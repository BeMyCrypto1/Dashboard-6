Can't reach the proxy. This page fetches DexPaprika data through a small local server, not the browser, so run it first:
1. In a terminal, in the same folder as this file: node proxy-server.js
2. Leave that running, then reload this page.
Data source: DexPaprika API (api.dexpaprika.com), reached through proxy-server.js running on localhost:8787 — the API itself doesn't send CORS headers, so a browser page can't call it directly; the proxy adds them. Prices come from the batched /multi/prices endpoint (falling back to the per-token endpoint for anything it omits) and refresh every 60 seconds. Trade rows come from each pool's /transactions endpoint and refresh every 120 seconds. Move arrows compare each price to the previous poll, not to a 24h figure — DexPaprika's batch price endpoint doesn't return a 24h change, so showing one would mean making it up. No API key is required for the public REST tier.
